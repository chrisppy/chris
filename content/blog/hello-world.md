Welcome to my new website.

I'm using this space to write about software development, NixOS, self-hosting,
open-source projects, and whatever else I'm working on.

The site itself is intentionally simple:

- Zola for static site generation
- Sass for styling
- Camden Base24 for the color palette
- Atom for the blog feed
- Cloudflare Pages for hosting
- Nix for reproducible tooling

No JavaScript is required.

The goal is a site that's fast, readable, easy to maintain, and pleasantly
boring to operate.
